# Dymok · Довідковий Telegram-бот

Готовий код довідкового бота українською. Є меню з кнопками та розпізнавання тем у текстових запитаннях. Це бот із підготовленою базою відповідей, без генеративного ШІ.

## Що вже є

- Чотири теми: обслуговування, повернення, приватність, вікові обмеження.
- Уточнення теми, якщо запитання стосується кількох розділів.
- Чесна відповідь, якщо потрібної інформації немає в джерелі.
- Відповіді лише в особистому чаті користувача.
- Без збереження переписки, пересилання повідомлень, збору контактів і геолокації.
- Повторне підключення після тимчасових мережевих помилок, підтримка обмежень частоти Telegram, зупинка через Ctrl+C.
- Захист від двох одночасних локальних запусків та збереження номера обробленої події між запусками.

Бот не має каталогу, рекомендацій товарів, кошика, оплати, приймання заявок чи передачі їх менеджеру.

## Спробувати без Telegram

Потрібен Python 3.9 або новіший на macOS чи Linux. Зовнішні бібліотеки не потрібні.

Відкрийте термінал у папці цього бота та виконайте:

```sh
python3 bot.py --demo
```

Приклади запитань: «Як повернути?», «Чи зберігаєте дані?», «Які вікові обмеження?». Команда `/exit` завершує локальний діалог. У демонстрації текст показується в терміналі; використовуйте тестові запитання без персональних даних.

## Підключити до Telegram

1. У Telegram відкрийте офіційного [BotFather](https://t.me/BotFather), створіть **окремого нового бота** командою `/newbot` та отримайте токен. Існуючі боти магазину змінювати не потрібно.
2. Скопіюйте `.env.example` у `.env` у цій папці:

   ```sh
   cp .env.example .env
   ```

3. Відкрийте `.env` у текстовому редакторі та впишіть токен після `TELEGRAM_BOT_TOKEN=`. Не публікуйте цей файл і не надсилайте токен у чат. За потреби замість файлу можна задати цю змінну середовища; вона має пріоритет.
4. Запустіть:

   ```sh
   python3 bot.py
   ```

   На Mac також можна двічі натиснути `Start.command`. Якщо система не дозволяє запуск файлу, використайте команду вище.

5. Відкрийте свого нового бота в Telegram та натисніть **Start**. Перевірте всі чотири кнопки та довільне запитання.

До додавання токена цей пакет не підключається до Telegram. Самостійно зареєструвати бота без вашого облікового запису та запустити його онлайн без токена неможливо.

Поки програма працює й має інтернет, бот відповідає. Для цілодобової роботи потрібен постійно ввімкнений комп’ютер або Linux-сервер із Python. Розгортання на сервері в цьому пакеті не виконувалося.

## Команди

| Команда | Дія |
| --- | --- |
| `/start`, `/menu`, `/help` | Головне меню |
| `/service` | Обслуговування |
| `/returns` | Повернення та гарантія |
| `/privacy` | Обробка даних |
| `/age` | Вікові обмеження |

Бот не реєструє список команд автоматично в BotFather: команди можна вводити вручну, а основна навігація доступна кнопками.

## Звідки взяті відповіді

Переглянуто локальний файл `Dymok_Web/index.html`, наданий користувачем, 6 листопада 2026 року.

- Рядки 703, 708–718: інформація 18+ та вікно самостійного підтвердження віку.
- Рядки 940–948: збереження профілю, кошика та історії у `localStorage` браузера. Опис стосується саме наданого файлу, а не перевіреної політики всього бізнесу.
- Окремих опублікованих правил повернення, гарантії, приватності та розгляду звернень у переданій папці немає. Бот прямо повідомляє про цю прогалину; строки або гарантії не вигадані.

Відповіді зберігаються у `faq.json`. Після зміни перевірених довідкових текстів перезапустіть програму. Це не автоматична синхронізація із сайтом. Розділ про приватність описує саме цей код; при зміні способу обробки даних оновіть і текст.

## Обробка даних і обмеження

Текст та ідентифікатор чату обробляються в пам’яті для відповіді. У файлах стану немає тексту, імен, юзернеймів чи контактів: лише номер наступної події та порожній файл блокування. Токен зберігається окремо у вашому `.env`. У службовий журнал не записуються переписка, токен чи адреси запитів.

Telegram продовжує обробляти повідомлення за власними правилами. Цей код не видаляє переписку з Telegram, не керує журналами зовнішнього хостингу та не виконує юридичну перевірку політик магазину.

База відповідей визначає теми за ключовими словами. Незрозумілі запитання повертають меню; складні формулювання можуть потребувати вибору кнопки. Бот не переглядає вкладення.

Після раптового збою між надсиланням відповіді та записом номера події можлива повторна відповідь. Запускайте лише одну копію бота, навіть на різних серверах. Якщо у токена вже є webhook, програма зупиниться й не змінить його.

## Перевірка

```sh
python3 bot.py --check
python3 -m unittest discover -s tests -v
```

Ці перевірки не підключаються до Telegram. Реальне надсилання потребує окремого тесту після додавання токена.

Для реалізації використано офіційний [Telegram Bot API](https://core.telegram.org/bots/api): отримання подій через `getUpdates`, відповіді через `sendMessage`, кнопки та `answerCallbackQuery`. Публічний вебсервер для такого запуску не потрібен.
