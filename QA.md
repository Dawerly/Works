# Результати перевірок

Дата: 6 листопада 2026 року. Перевірена локальна оновлена копія.

**74 перевірки пройдено: 58 перевірок JavaScript і поведінки в Chrome, 16 статичних перевірок.** У фінальному прогоні немає невдалих перевірок, необроблених помилок JavaScript або відсутніх локальних ресурсів.

## Середовище

- Chrome 156.0.8078.80 у headless-режимі, ізольований тимчасовий профіль.
- Локальний HTTP-сервер і окреме відкриття через `file://`, як подвійним натисканням на файл.
- Ширини екрана: 320, 360, 390, 480, 600, 760, 768, 820, 1024, 1100, 1440 і 1920 px.
- Додатково: короткий горизонтальний екран 812 × 320, збільшення тексту до 200%, зменшення анімації, заборонений localStorage і вимкнений JavaScript.
- Зовнішні мережеві відповіді підмінялися порожніми. Справжні зовнішні сайти не відкривалися.

## Що перевірено

| Група | Перевірка |
|---|---|
| Код | Синтаксис кожного скрипта та їх спільної області змінних |
| Розмітка | Унікальні id, один main, підписи навігації й коректні ARIA-посилання |
| Ресурси | Локальні CSS, JavaScript, логотип та інші локальні підключення |
| Верстка | Відсутність горизонтального виходу сторінки та шапки на 12 ширинах |
| Навігація | Переходи на головну й у кабінет, активні пункти, перехід за невідомим маршрутом |
| Клавіатура | Логотип, перехід до основного вмісту, видимий фокус і розкриття інформації про дані |
| Перевірка віку | Перший візит, збережене підтвердження, Tab, Shift+Tab, inert-фон, фокус і прокручування |
| Стійкість | Робота вікового вікна без localStorage; повідомлення без JavaScript |
| Загальні інструменти | Кнопка вгору, фокус після натискання, вимірювання висоти шапки |
| Збирання | Повторюваний результат, наявність файлів, відхилення виходу за папку й неправильного розширення |
| Обсяг змін | Контрольні суми вихідних даних і логіки, що не змінювалися |

Візуально перевірено знімки головної сторінки для комп’ютера та телефона: `tests/desktop.png` і `tests/mobile.png`.

## Межі результату

- Це перевірки загального інтерфейсу, а не повний тест усіх можливих дій на сайті. Вибір товарів, кошик, оформлення, передавання повідомлень і платежі не перевірялися та не змінювалися.
- Відповідність товарних фото, наявність товарів, відповіді зовнішніх сервісів і завантаження реальних зовнішніх шрифтів не перевірялися.
- Safari, Firefox, справжні телефони та читачі екрана окремо не тестувалися. Перевірки доступності не є підтвердженням повної відповідності WCAG.
- Збережений профіль залишається локальним записом без парольного захисту; серверної авторизації немає. Повний аудит захисту персональних даних не проводився.
- Числових порівнянь швидкодії та Lighthouse-звіту немає. Оптимізації загальних ресурсів не слід сприймати як підтверджений приріст швидкості.

Докладні результати кожного пункту — `tests/browser-results.json` і `tests/static-results.json`. Скрипти для повторення перевірок та інструкції включені в архів.
