# Перевірка релізу v3

67 серверних перевірок пройдено, включно з новими перевірками емодзі, збереження після перезапуску, міграції та відхилення HTML. Чотири браузерні сценарії пройдено без помилок JavaScript: вибір і попередній перегляд; створення/редагування та повторне відкриття; плитка каталогу на телефоні; безпечне відображення тексту замість виконання HTML.

Попередні функції акаунтів, відстеження, доставки та кур’єрів збережені. Каталог і залишки з наданої бази збережено; тестових даних у релізі немає. Опублікований сайт не змінювався. Інструкція — README_DELIVERY.md.
